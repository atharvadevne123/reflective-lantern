# Contributing to Cart-Mind

## Setup

```bash
git clone https://github.com/atharvadevne123/Cart-Mind
cd Cart-Mind
pip install -r requirements.txt
```

## Running tests

```bash
make test
```

## Code style

All code must pass `ruff check .` and `ruff format --check .` before merging.

## Pull requests

- One feature or fix per PR
- Include tests for new functionality
- Update CHANGELOG.md
